# 나만의 졸업식장 만들기 웹앱

## GitHub Pages 배포
1. GitHub에서 새 저장소를 만들거나 기존 저장소를 엽니다.
2. 이 폴더 안의 `index.html`과 `README.md`를 저장소 최상위에 업로드합니다.
3. **Settings → Pages → Build and deployment**로 이동합니다.
4. **Deploy from a branch**를 선택하고 Branch `main`, 폴더 `/(root)`를 지정해 저장합니다.
5. 잠시 후 Pages 설정 화면에 표시되는 주소로 접속합니다.

## 이미지 게시물 기능
MBTI 캐릭터, 내가 나에게 주는 상, 중학교 3년 데이터 이미지 파일을 각 항목에서 선택해 미리 볼 수 있습니다. 선택 이미지는 브라우저에서만 미리보기로 사용됩니다. 생성된 프롬프트와 이미지 파일을 이미지 생성 도구에 함께 첨부하면 세 이미지를 각각의 게시물 카드로 배치하도록 요청할 수 있습니다.
