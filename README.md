# 나만의 졸업식장 만들기 웹앱

## GitHub Pages 배포 방법
1. GitHub에서 새 저장소를 만들거나 기존 저장소를 엽니다.
2. 이 폴더 안의 `index.html`과 `README.md`를 저장소 최상위에 업로드합니다.
3. 저장소에서 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 **Deploy from a branch**를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`로 지정하고 저장합니다.
6. 잠시 후 Pages 설정 화면에 표시되는 주소로 접속합니다.

이 웹앱은 별도의 서버나 라이브러리 없이 동작하는 단일 HTML 파일입니다. 학생 입력 내용은 브라우저 안에서 프롬프트를 만드는 데 사용되며, 별도 서버로 전송하지 않습니다.
